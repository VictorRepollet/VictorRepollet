## 🚀 Proyectos

### 🌍 Feed the World — Juego ODS

Juego educativo interactivo desarrollado durante **DAW 1** basado en los **Objetivos de Desarrollo Sostenible de la ONU**.

El proyecto está desarrollado con **JavaScript Vanilla, HTML y CSS** y utiliza el patrón arquitectónico **MVC**.

Entre sus funcionalidades se encuentran:

* 🎮 Juego basado en Drag & Drop
* ⏱️ Temporizador de 60 segundos
* 🏆 Sistema de puntuaciones y ranking
* 👤 Gestión de jugadores mediante CRUD
* 🔎 Búsqueda, filtrado y ordenación
* 📝 Formularios con validación
* 🧩 Arquitectura MVC
* 📦 Módulos ES6
* 🔀 Trabajo colaborativo mediante Git y Pull Requests

🔗 **[Ver ProyectoJuegoODS](https://github.com/VictorRepollet/ProyectoJuegoODS)**

`JavaScript` `HTML` `CSS` `MVC` `Git`

---

### 🎭 Juego Memes 8M

Juego desarrollado en **Java** durante DAW 1.

Se trata de un juego por consola en el que el jugador debe identificar la realidad correcta asociada a diferentes memes relacionados con el 8M.

El proyecto trabaja con diferentes formatos de datos y cuenta con una estructura organizada de código, documentación y pruebas.

Entre sus características:

* ☕ Aplicación desarrollada en Java
* 🎮 Juego por consola
* 📄 Lectura de datos desde TXT
* 🔵 Procesamiento de JSON
* 🟢 Procesamiento de XML
* 🏆 Sistema de ranking
* 🧪 Pruebas unitarias
* 📚 Documentación del proyecto
* 🔀 Trabajo con Git

🔗 **[Ver ProyectoMemes8M](https://github.com/VictorRepollet/ProyectoMemes8M)**

`Java` `JSON` `XML` `Git`
